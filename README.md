# 🎮 Tic Tac Toe Using C++

## 📌 Overview

A simple Tic Tac Toe game developed using C++ programming language. The game allows two players to play turn by turn on a 3x3 board.

## ✨ Features

- Two-player gameplay
- Winner detection
- Draw detection
- Simple console interface

## 🛠 Technologies Used

- C++
- GCC/G++ Compiler
- Git
- GitHub

## 🚀 How to Run

Compile:

```bash
g++ tictactoe_game.cpp -o tictactoe_game
```

Run:

```bash
./tictactoe_game
```
